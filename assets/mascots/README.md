# BBuidl Lab mascot references

`bbuidl-mascots-board.svg` is a presentation-ready reference board with five mascot directions derived from the uploaded hand-drawn dog on a magenta shirt.

## Directions

- **Mochi Scout** — curious, observant; for research and discovery.
- **Mochi Buidler** — steady, practical; for building and shipping.
- **Mochi Spark** — playful, electric; for launches and announcements.
- **Mochi Guard** — calm, dependable; for principles and trust.
- **Mochi Guide** — warm, articulate; for education and community.

## Design system

All five share the same floppy-eared dog silhouette, question/star language, hand-drawn line quality, and BBuidl palette: Forest `#183E35`, Paper `#F4F1E9`, Citron `#D9EF87`, with a soft magenta/pink secondary accent sampled from the reference garment.

These are concept references, not a final trademark or production character sheet. The strongest candidate for a primary startup mascot is **Mochi Scout**: it carries the original question-mark idea most directly and can flex from curious beginner to serious builder.
