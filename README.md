# BBuidl AI Lab

Website tĩnh của BBuidl AI Lab.

Mở `index.html` trực tiếp trong trình duyệt hoặc deploy toàn bộ thư mục này lên một static host. Không cần Node.js, package manager, build step hay server-side runtime.

## Cấu trúc

- `index.html` — trang website duy nhất
- `assets/` — stylesheet, JavaScript, font và asset runtime
- `dist/` — hình ảnh và vector runtime
- `design/` — tài liệu nhận diện thương hiệu

Các gói ZIP là deliverable tải xuống được liên kết từ website; giữ chúng cùng cấp với `index.html` khi deploy.
